# Security Policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub Security Advisories:
[Report a vulnerability](https://github.com/aimanmalib/documind/security/advisories/new)
(repository **Security** tab → **Report a vulnerability**).

Include a description, steps to reproduce, the affected version or commit, and
the impact you expect. You should get an acknowledgement within a few days; once
a fix is ready we will publish an advisory and credit you unless you prefer
otherwise.

DocuMind sends document text to the LLM endpoint you configure. Treat that
endpoint as a recipient of your documents, and never commit API keys.
